The first release of Rail Narrator. It reads a PDF aloud, highlights the passage being spoken in the
page itself and keeps it in view, and can say what the mathematics means rather than reading out
its symbols.

## Downloads

| | |
|---|---|
| **Linux (x64)** | `rail-narrator-0.1.0-linux-x64.tar.gz`. Needs PortAudio (`libportaudio2` on Debian and Ubuntu, `portaudio` on Fedora) and glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later). |
| **Windows (x64), preview** | `rail-narrator-0.1.0-win-x64.zip`. Built and tested automatically, but **not yet run on a Windows PC**. It is not code-signed, so SmartScreen may warn: choose *More info* ▸ *Run anyway*. |

`SHA256SUMS.txt` has the checksums.

## Before you start

No speech model is included, and none is downloaded unless you ask. Get a voice first:

- **Kokoro:** in the app, *Models and endpoints* ▸ *Download Kokoro speech model* (164 MB).
- **Phonon:** faster, with word-by-word highlighting built in. Run `install-phonon.sh` from the
  unpacked folder (about 70 MB; needs `curl`; on Windows, from Git Bash).

Then choose it in *Settings* ▸ *Speech*. The [README](https://github.com/sjvrensburg/rail-narrator#readme)
covers the layout model, reading maths with a local model or Claude, and the keyboard shortcuts.

## In this release

- Reading aloud with the passage highlighted where it is printed, word by word with a voice that
  times its words, and the view following the reading.
- Maths read for its meaning through a language model you choose (any OpenAI-compatible server,
  or Claude), an optional formula model that reads display equations on your computer, and a
  spoken reading of the notation when neither is set up.
- Running heads, footnotes, references, figures, contents pages and front matter skipped.
- Notes and highlights while you listen, kept beside the PDF, never in it, and exported as
  Markdown, an annotated copy or RailReader2 annotations.
- A whole document narrated ahead of time and played with no model, and an audiobook (M4B) made
  from it (needs ffmpeg, which you install yourself).

## Known limitations

English only. The Windows build has not yet been run on a Windows PC. The optional forced aligner
is Linux-only and installed from source. Pages are shown one at a time. See the
[status page](https://github.com/sjvrensburg/rail-narrator/blob/main/docs/status.md) for what has
been verified and how.
