A packaging release: two easier ways to install, and Phonon from inside the app.

## Downloads

| | |
|---|---|
| **Linux, AppImage** | `rail-narrator-x86_64.AppImage`: make it executable and run it. It carries its own PortAudio, so nothing else needs installing. [AppImageUpdate](https://github.com/AppImageCommunity/AppImageUpdate) can update it from here on (`.zsync` beside it). |
| **Linux, archive** | `rail-narrator-0.1.1-linux-x64.tar.gz`, as before. Needs PortAudio (`libportaudio2` on Debian and Ubuntu, `portaudio` on Fedora). |
| **Windows, installer (preview)** | `rail-narrator-setup-x64.exe`: installs for your user without administrator rights, with a Start menu entry and, if you choose, *Open with* for PDFs. |
| **Windows, zip (preview)** | `rail-narrator-0.1.1-win-x64.zip`, as before. |

Both Linux downloads need glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later). The
Windows downloads are built and tested automatically, the installer installed, run and
uninstalled, but they have **not yet been run on a Windows PC**. They are not code-signed, so
SmartScreen may warn: choose *More info* ▸ *Run anyway*. `SHA256SUMS.txt` has the checksums.

## What's new

- **Phonon from inside the app.** *Models and endpoints* ▸ *Download Phonon speech model* (71 MB)
  fetches Phonon's model and its 25 British and American voices, each file checked against its
  published digest. On Windows this replaces running `install-phonon.sh` from Git Bash, which still
  works.
- **AppImage** for Linux, with sound built in.
- **Installer** for Windows.

## Known limitations

As in 0.1.0: English only; the Windows builds have not yet been run on a Windows PC; the optional
forced aligner is Linux-only and installed from source; pages are shown one at a time.
