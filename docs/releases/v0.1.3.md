A bug-fix release: smaller problems found by stress-testing the application.

## Fixed

- **Pressing Play/Pause quickly no longer loses a press.** About one press in 40 had no effect
  when the key was pressed repeatedly; every press now counts.
- **Keys are ignored while a file dialog is open.** The Open dialog does not block the main
  window, so pressing Space in it could start reading behind it. The window now ignores keys and
  typing until the dialog closes.
- **The status bar names the section being read.** When a new heading starts part way down a
  page, the status bar used to name it while the end of the section before was still being read.
  It now changes when the heading is read. A long section name is shortened from the start, so the
  innermost heading (4.2, 4.3) stays visible.
- **The last word is no longer left highlighted** when the document has been read to the end.
- **The welcome screen no longer shows the progress bar, page and zoom** of a closed document.
- **Notices are shown in full.** A notice may take two lines, and the question offering Phonon's
  speech model is shorter.

checksums.

## Known limitations

As before: English only; the Windows builds have not yet been run on a Windows PC; the optional
forced aligner is Linux-only and installed from source; pages are shown one at a time. A rotated
scanned page can still have a phrase read twice where two sideways lines meet.
